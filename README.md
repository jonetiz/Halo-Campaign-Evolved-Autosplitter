# Halo: Campaign Evolved Autosplitter

## Description
This is an autosplitter and load remover for Halo: Campaign Evolved; currently only validated for Build 2026.06.26.1097863 (23 July Pre-release), but with intent to update as the game is updated.

## Features
- Start timer when initial level cutscene is skipped
- Load removal (currently configured to treat main menu as loads)
- Split when level changes
